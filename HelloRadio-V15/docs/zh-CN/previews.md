# 32 套完整动图

[English](../en/previews.md) · [灯效目录](effects.md)

[打开全部 32 套同屏总览](../../previews/zh-CN/overview.gif)

一张总览和 32 张独立动图；每张 12 秒、20 帧/秒，演示亮度 65%。B 组展示油门 0% → 100% → 0%；C04 演示三种组合动作。B01 示范彩虹配色、两侧展开、内下角起点。

画面来自 Lua 实际输出的电脑模拟，非实机拍摄。灯罩、固件和 GIF 色彩量化会影响观感；12 秒后重播，部分效果的周期不在接缝处结束。
