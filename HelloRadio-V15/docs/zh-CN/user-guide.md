# HelloRadio V15 使用说明

[English](../en/user-guide.md) · [灯效目录](effects.md) · [动图预览](previews.md)

## 兼容范围

当前适配 HelloRadio V15 的两圈各 16 颗装饰灯及六个按键灯。校准工具需要 EdgeTX LVGL；固件需提供 RGB LED Lua 接口。其他遥控器须单独适配，不能仅凭外形相似直接使用。

## 安装与选择灯效

1. 将本型号包的 **SCRIPTS** 合并到遥控器 SD 卡根目录，得到 SCRIPTS/RGBLED 和 SCRIPTS/TOOLS。
2. 保留 SD 卡已有的 RGBLED/v15lib/layout.cfg；不要删除整个 v15lib。*.luac 是设备生成的编译缓存，替换源文件后遇到旧版本可删除对应缓存。
3. 安全退出 USB 存储并重启。从 SYS 工具页运行 **v15map**。已完成 v5.1 校准的用户不用重校。
4. 模型特殊功能：选择 **RGB LED 灯 → 一个 A/B/C 文件 → 循环 ON → 启用**，一次只开一条灯效。全局特殊功能也应检查，避免同时写灯。
5. 需要随解锁开关亮灯时，使用已有的解锁条件触发该条特殊功能。

从旧 v15xxx 名称升级时，先把模型 / 全局 RGB 特殊功能引用改为新名，再删除旧入口及对应缓存。工具 v15map 和公共库 v15lib 名称不变。

## 四步校准

遥控器正面朝向自己，屏幕在下方：

1. 在灯组 1 选择约 6 点钟的灯珠，注明它实际属于左杆还是右杆，再点“确定灯位”。
2. 白灯应当顺时针移动；方向不对点“反转方向”，确认后点“方向正确”。
3. 灯组 2 同样选择 6 点钟灯珠。
4. 同样确认灯组 2 顺时针方向，回到主页，点“保存设置”，再点“返回”退出。

保存写入 /SCRIPTS/RGBLED/v15lib/layout.cfg，不修改模型、混控和通道。返回特殊功能重新启用灯效可重读设置。每圈 16 颗灯，每步约 22.5°；内下角约左 5:15 / 右 6:45，实际位置以校准为准。

v15map 只负责校准和通用设置。主页保留“设置、关于、重新校准、保存设置、返回”，每页只有一个“返回”按钮，按层级退回，主页的“返回”退出工具。按钮文字按固件实际字体高度水平、垂直居中。

“设置”直接调整亮度、六键开关和低功耗；“油门设置”调整来源、反向和平滑。修改后返回主页点“保存设置”。配色、静态测试、按键灯测试和油门预览入口已移除；工具只在校准时点亮定位白灯，不播放另一套灯效。日常使用预设灯效，校准一次后在模型特殊功能中选择 A/B/C 文件即可。

## 设置适用范围

- 共用：灯位、左右侧、编号方向、亮度、六键开关、低功耗时间。
- A 组自动播放，灯效不随油门改变；配色和走向由各预设固定。启用低功耗后会读取操作状态以计时。
- B 组读取“设置 → 油门设置”里的来源、反向和平滑。B01-user 保留历史配置里的配色、走向和起点，新安装默认彩虹镜像；精简工具不再修改这些值。B02～B14 使用各自固定样式。B15 是随油门移动的加力亮斑。
- C 组按 Mode 1～4 换算物理左右摇杆，使用亮度、平滑和六键设置；不使用油门 CHn、反向及 B01 的配色选项。

来源“油门摇杆”读取物理杆；CHn 读取对应输出。通道监视器 -100% / 0% / +100% 对应进度 0% / 50% / 100%。标准平滑约 80ms，更新最多 20Hz。脚本只显示灯光。

## 低功耗（闲置熄灯）

进入 **v15map → 设置**，直接在“低功耗”选项中选择 **关闭 / 5分钟 / 10分钟 / 15分钟**，点“返回”回主页并点“保存设置”，重新启用当前灯效后生效。默认关闭，旧校准文件升级后也保持关闭，无需重校。

全部 32 套 A/B/C 灯效共用此设置：操作停止达到所选时间后，熄灭脚本控制的灯环和按键灯，暂停动画计算；再次操作自动恢复当前灯效并重新计时。脚本不修改遥控器电源、屏幕、模型或通道设置。

操作检测包括摇杆、旋钮/滑杆、拨杆、微调，以及固件能读取状态的 SW1～SW6；摇杆小幅抖动不会一直延长计时，灯效自身的颜色变化、遥测和输出通道变化也不会。校准白灯也遵守闲置时间，v15map 内操作可唤醒白灯；主页和设置页保持灯环熄灭。

EdgeTX RGB 后台脚本不接收 SYS/RTN 等菜单键和触屏事件；仅在系统菜单内操作不能保证唤醒，可动一下摇杆或拨杆。自定义按键被固件禁用或不提供状态时，也无法作为唤醒来源；未授权 Lua 控制的按键指示灯仍由固件管理。

## 六个按键灯

油门灯先按 **3/4 → 2/5 → 1/6 → 灯环** 点亮，按正面从左到右数 1～6。六键占总进度 3/19，所以整体 50% 时灯环并非刚好一半。

模型“自定义按键”中，启用的按键要在关闭和 ON 两列均打开“允许 LUA 脚本控制”。禁用的按键可保持禁用。工具“设置 → 六键”选择“开启”，保存并重新启用灯效。

灯效关闭六键时会释放自己持有的按键颜色覆盖；v15map 不探测、不接管按键灯，不改变按键原有用途。

## 双杆与组合拳

C01 跟随方向和偏转幅度；C02 左杆调颜色/亮度、右杆调速度/方向/宽度；C03 两圈独立旋转。C04 的三种动作：

1. 左右横向居中约半秒，油门可以保持最低。
2. 两步动作各停约半秒，在 2.5 秒内接上：**向外→向内**触发粉白星环；**向内→向外**触发冰蓝冲击；**同右→同左**触发彩虹回旋。
3. 动画约 2.4 秒，结束后横向居中才能再次触发。测试动作时让飞机断电。

## 乱色与排查

先确认模型和全局特殊功能中只启用了一条 RGB 灯效。灯位或方向不对时，停用灯效后运行 v15map 重新校准并保存。定位白灯也出现粉绿乱色、灯位错移时，应检查固件、硬件及其他写灯功能。

EdgeTX [修复 #7620](https://github.com/EdgeTX/edgetx/pull/7620) 涉及灯带 DMA 传输和数据线，后来回补至 2.12.3；厂商自编译版本是否包含修复需另行确认。Lua 不能保证修复底层传输故障；只使用明确支持本机型的固件。

106 项本地模拟检查通过，覆盖精简菜单与逐级返回、三种屏幕尺寸、多种字体高度、无字符串元表、校准、按键权限、全部灯效闲置熄灯与唤醒、关于页，以及仅更新变化灯珠的刷新逻辑；模拟检查不等于硬件实机认证。
