# HelloRadio V15 使用说明

[English](../en/user-guide.md) · [灯效目录](effects.md) · [动图预览](previews.md)

## 兼容范围

当前适配 HelloRadio V15 的两圈各 16 颗装饰灯及六个按键灯。校准工具需要 EdgeTX LVGL；固件需提供 RGB LED Lua 接口。其他遥控器须单独适配，不能仅凭外形相似直接使用。

## 安装与选择灯效

1. 将本型号包的 **SCRIPTS** 合并到遥控器 SD 卡根目录，得到 SCRIPTS/RGBLED 和 SCRIPTS/TOOLS。
2. 保留 SD 卡已有的 RGBLED/v15lib/layout.cfg；不要删除整个 v15lib。*.luac 是设备生成的编译缓存，替换源文件后遇到旧版本可删除对应缓存。
3. 安全退出 USB 存储并重启。从 SYS 工具页运行 **v15map**。已完成 v5.1 校准的用户不用重校。
4. 模型特殊功能：选择 **RGB LED 灯 → 一个 A/B/C 文件 → 循环 ON → 启用**，一次只开一条灯效。全局特殊功能也应检查，避免同时写灯。
5. 需要随解锁开关亮灯时，使用已有的解锁条件触发该条特殊功能。

从旧 v15xxx 名称升级时，先把模型 / 全局 RGB 特殊功能引用改为新名，再删除旧入口及对应缓存。工具 v15map 和公共库 v15lib 名称不变。

## 四步校准

遥控器正面朝向自己，屏幕在下方：

1. 在灯组 1 选择约 6 点钟的灯珠，注明它实际属于左杆还是右杆，再点“确定灯位”。
2. 白灯应当顺时针移动；方向不对点“反转方向”，确认后点“方向正确”。
3. 灯组 2 同样选择 6 点钟灯珠。
4. 同样确认灯组 2 顺时针方向，进入预览，点“保存设置”。

保存写入 /SCRIPTS/RGBLED/v15lib/layout.cfg，不修改模型、混控和通道。返回特殊功能重新启用灯效可重读设置。每圈 16 颗灯，每步约 22.5°；内下角约左 5:15 / 右 6:45，实际位置以校准为准。

预览页使用“重新校准”和“保存设置”；设置、配色、测试及关于页的“返回预览”回到预览页。静态测试和按键灯测试使用完整中文按钮，文字在按钮内水平、垂直居中。

## 设置适用范围

- 共用：灯位、左右侧、编号方向、亮度、六键开关。
- A 组自动播放，不读取油门；配色和走向由各预设固定。
- B 组读取工具里的来源、反向和平滑。B01-user 还使用工具自选的配色、走向和起点；B02～B14 固定这些选项。B15 是随油门移动的加力亮斑。
- C 组按 Mode 1～4 换算物理左右摇杆，使用亮度、平滑和六键设置；不使用油门 CHn、反向及 B01 的配色选项。

来源“油门摇杆”读取物理杆；CHn 读取对应输出。通道监视器 -100% / 0% / +100% 对应进度 0% / 50% / 100%。标准平滑约 80ms，更新最多 20Hz。脚本只显示灯光。

## 六个按键灯

油门灯先按 **3/4 → 2/5 → 1/6 → 灯环** 点亮，按正面从左到右数 1～6。六键占总进度 3/19，所以整体 50% 时灯环并非刚好一半。

模型“自定义按键”中，启用的按键要在关闭和 ON 两列均打开“允许 LUA 脚本控制”。禁用的按键可保持禁用。工具“配色 → 六键”选择“优先点亮”；“测试 → 测试按键灯”可检查接口响应。6/6 表示接口接受请求，不保证两列权限已经打开。

关闭六键或退出工具会释放本工具持有的按键颜色覆盖；不会改变按键原有用途。

## 双杆与组合拳

C01 跟随方向和偏转幅度；C02 左杆调颜色/亮度、右杆调速度/方向/宽度；C03 两圈独立旋转。C04 的三种动作：

1. 左右横向居中约半秒，油门可以保持最低。
2. 两步动作各停约半秒，在 2.5 秒内接上：**向外→向内**触发粉白星环；**向内→向外**触发冰蓝冲击；**同右→同左**触发彩虹回旋。
3. 动画约 2.4 秒，结束后横向居中才能再次触发。测试动作时让飞机断电。

## 乱色与排查

停用所有 RGB 特殊功能，工具进入“测试”，使用“半圈青色 / 全部青色 / 全部红色 / 全部蓝色 / 关闭灯环”。静态图案仍出现粉绿乱色、灯位错移时，应检查固件、硬件及其他写灯功能。

EdgeTX [修复 #7620](https://github.com/EdgeTX/edgetx/pull/7620) 涉及灯带 DMA 传输和数据线，后来回补至 2.12.3；厂商自编译版本是否包含修复需另行确认。Lua 不能保证修复底层传输故障；只使用明确支持本机型的固件。

95 项本地模拟检查通过，覆盖三种屏幕尺寸、按钮居中、无字符串元表、校准、按键权限、油门和双杆动画、关于页，以及仅更新变化灯珠的刷新逻辑；模拟检查不等于硬件实机认证。
